# Análisis de campañas bancarias

Aplicación interactiva desarrollada con Streamlit para explorar y analizar datos de campañas bancarias. El proyecto utiliza el dataset Bank Marketing y permite consultar estadísticas descriptivas, distribuciones y relaciones entre variables. Su objetivo es apoyar el análisis y la toma de decisiones; no genera predicciones ni entrena modelos.

## Instrucciones de ejecución

### Requisitos

- Python instalado.
- Las dependencias: Streamlit, pandas, NumPy, Matplotlib y Seaborn.

### Windows (PowerShell)

Desde la carpeta del proyecto:
python -m pip install streamlit pandas numpy matplotlib seaborn
streamlit run app.py


Al iniciar, Streamlit mostrará la dirección local de la aplicación en la terminal. En la barra lateral, selecciona **Módulo 2 - Análisis Exploratorio de Datos** y carga `BankMarketing.csv`. La aplicación lee archivos CSV con `;` como separador.

## Funcionalidades

- Presentación del proyecto y las tecnologías utilizadas.
- Vista previa y dimensiones del dataset cargado.
- Clasificación de variables numéricas y categóricas.
- Estadísticas descriptivas e identificación de valores faltantes.
- Gráficos de distribución numérica y categórica.
- Análisis bivariado y análisis dinámico de variables seleccionadas.
- Resumen visual y hallazgos descriptivos.
